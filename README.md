# ABSKA — 214 | التحوّل الشامل
### نظام التطوير الشخصي التقدمي (PWA) المتكامل — 214 يومًا

ABSKA 214 هو تطبيق ويب تقدمي (Progressive Web App) مبني بأعلى معايير هندسة البرمجيات، يهدف إلى إحداث تحوّل شامل ومتدرج في حياة المستخدم على مدار 214 يومًا بالضبط. التطبيق مصمم بالكامل باللغة العربية مع اتجاه RTL أصيل وهوية بصرية سينمائية فخمة باللونين الأسود والماروني (`#0B0B0D`, `#151316`, `#6D1028`, `#922D48`).

---

## 🌟 الميزات الجوهرية المنفذة بالكامل

1. **الإعداد الأولي وميثاق الرحلة (15 سؤالًا متكاملًا)**:
   - جمع الاسم، سنة الميلاد، الطول، الوزن الاختياري، الأهداف، المسارات، النشاط، أوقات النوم والاستيقاظ، الصعوبة، أيام الراحة.
   - خيارات افتراضية محافظة وواقعية قابلة للتعديل لاحقًا.
   - زر «ابدأ رحلتي» الذي يحسب ويثبّت تاريخ البداية ونهاية الرحلة بعد 214 يومًا بالضبط دون تغيير عند التحديث.
   - كتابة وتشفير «رسالة اليوم الأول إلى النفس المستقبلية» لتبقى مختومة حتى اليوم 214.

2. **لوحة القيادة الذكية (Dashboard)**:
   - تحية مخصصة بحسب الوقت واسم المستخدم.
   - عداد اليوم الحالي من أصل 214 والأيام المتبقية ونسبة التقدم الزمني الدقيقة.
   - المستوى الحالي ونقاط الخبرة (XP) وسلسلة الاستمرارية (Streak).
   - ملخص مهام اليوم، مسجل مستوى الطاقة اليومي (1 إلى 5).
   - أزرار الوصول السريع: «ابدأ مهام اليوم»، «وضع اليوم الصعب»، «تسجيل سريع».
   - مؤشر التحول الشامل عبر المسارات.

3. **نظام المهام المتدرج بالتكيّف الذكي بالقواعد المحلية**:
   - مهام يومية، أسبوعية، وتحديات مرحلية.
   - تصنيف الصعوبة، الوقت المقدر، التوقيت، ونقاط الخبرة.
   - محرك تكيف محلي يقترح تلقائيًا تجزئة المهام التي تتكرر فيها حالات التأجيل لأكثر من مرتين، أو تقليص الأحمال، مع اشتراط موافقة المستخدم.

4. **شجرة تطوير الشخصية (7 مسارات مستقلة)**:
   - الجسم واللياقة، الانضباط والاستمرارية، المعرفة والقراءة، المهارات والمشاريع، تنظيم الوقت، اكتشاف الذات، العادات والروح.
   - مستويات مستقلة ومعالم متدرجة؛ لا يلغي تعثر مجال تقدم مجال آخر.

5. **نقاط الخبرة والألقاب والأوسمة**:
   - نظام خبرة عادل وغير مكرر مع منع الازدواجية عند إعادة التحميل.
   - 8 ألقاب رتبية تفتح تصاعديًا (المستكشف الواعي، الباني المنضبط، الصامد المتزن، القارئ المفكر...).
   - أوسمة إنجاز متنوعة غير مرتبطة بالوزن إطلاقًا (أول كتاب، صانع المشاريع، منظم الأسبوع، عائد بقوة، الصامد في العاصفة...).
   - سجل تدقيق مالي لنقاط الخبرة (XP Ledger) يوضح تاريخ وسبب كل إضافة.

6. **خريطة رحلة الـ 214 يومًا وأداة المحاكاة**:
   - تقسيم الرحلة إلى 8 مراحل (المراحل 1-7 كل منها 30 يومًا، والمرحلة الختامية 4 أيام).
   - عرض أيام المرحلة بدقة وحالة كل يوم.
   - شريط أدوات محاكاة متقدم (QA Simulation Toolbar) يتيح اختبار الأيام المفصلية (اليوم 1، 30، 31، 210، 214) ومعاينة ردود فعل التطبيق الفورية.

7. **تحديات كل 30 يومًا وعقد المرحلة (Phase Contract)**:
   - وثيقة عقد رسمي لكل مرحلة تتضمن الهدف الأساسي، أهم 3 أهداف، ما يتوقف عنه المستخدم، الحد الأدنى المقبول، خطة الأيام الصعبة، والمكافأة.
   - توقيع إلكتروني وحفظ تاريخي مع توثيق سجل المراجعات والتعديلات.
   - تقرير التحول والمراجعة المرحلية عند نهاية كل مرحلة.

8. **نظام الإنقاذ «العودة إلى المسار» (Comeback System)**:
   - خطاب هادئ خالٍ من أي تأنيب أو لوم.
   - تشخيص متعدد الأسباب (وقت، طاقة، تشتت، ظروف خارجية...).
   - اختيار خطوة مصغرة واحدة لاستعادة الزخم وإعادة جدولة اليوم دون تصفير الرحلة أو خصم نقاط.

9. **وضع اليوم الصعب (Hard Day Mode)**:
   - تقليص قائمة المهام إلى الحد الأدنى الواقعي الآمن.
   - قائمة عادات مصغرة (قراءة صفحة، مشي 5 دقائق، ترتيب مساحة صغيرة).
   - تسجيل اليوم كيوم ناجح مع منح نقاط صادقة للمهام المنجزة فعليًا.

10. **مكتبة القراءة والتطبيق العملي**:
    - إدارة الكتب، نسبة القراءة، الاقتباسات، والأفكار.
    - زر «حوّل إلى مهمة عملية» لترجمة الفكرة النظرية إلى مهمة تنفيذية مباشرة في جدول المهام.

11. **مشروع مهارة لكل مرحلة**:
    - تحديد المهارة والمخرج العملي النهائي وتقسيم المشروع إلى معالم فرعية تفاعلية.

12. **دفتر اكتشاف الذات**:
    - أسئلة تأمل موجهة يومية (ما سار جيدًا، ما كان صعبًا، ما تعلمته، ما العادة التي أريد فهمها، الامتنان، والقيم).

13. **إدارة الوقت والمخطط الزمني**:
    - فترات زمنية للمجالات مع تنبيه ذكي لتداخل الأوقات ومقارنة المخطط بالفعلي.

14. **المتابعة البدنية والصور التوثيقية**:
    - متابعة النشاط والوزن والقياسات اختياريًا.
    - حفظ الصور محليًا بضغط آمن وعرض المقارنة البصرية دون إرسال أي صورة للإنترنت.

15. **الخصوصية والنسخ الاحتياطي (IndexedDB + JSON)**:
    - تصدير كامل لقاعدة البيانات في ملف JSON موثق.
    - استيراد مع فحص ومعاينة للتأكد من سلامة البنية قبل الاستبدال.
    - إمكانية إعادة ضبط التطبيق بتحذير وتأكيد صريح.

16. **جاهزية PWA والعمل دون إنترنت الكامل**:
    - ملف `manifest.webmanifest` متوافق مع معايير Android وChromium.
    - تسجيل Service Worker عبر `vite-plugin-pwa` مع تخزين Cache Storage للملفات والخطوط.
    - زر تثبيت ذكي `PWAInstallButton` يدعم التثبيت المباشر على أندرويد ويوفر دليلًا مصورًا لأجهزة iOS Safari.
    - مؤشر حالة الاتصال `OfflineIndicator`.

## 🚀 طريقة التشغيل والتثبيت محليًا

### 1. تثبيت الحزم وتشغيل خادم التطوير
```bash
npm install
npm run dev
```
سيفتح التطبيق على المنفذ `http://localhost:3000`.

### 2. البناء للإنتاج (Production Build)
```bash
npm run build
```
تُنتج هذه الخطوة الملفات المجمعة والمحسنة داخل مجلد `dist/` مع الـ Service Worker الجاهز للعمل دون اتصال.

### 3. التثبيت كتطبيق PWA
- **على هواتف أندرويد (Google Chrome)**: اضغط على زر «تثبيت التطبيق» الظاهر في الترويسة، أو من قائمة المتصفح اختر "Install App".
- **على هواتف آيفون (iOS Safari)**: اضغط على زر المشاركة (Share) في المتصفح ثم اختر "إضافة إلى الشاشة الرئيسية" (Add to Home Screen).

## 🧪 نتائج خطة الاختبار الإلزامية (Section 34)

- **اختبار الإعداد والرحلة**:
  - تم تجربة إكمال استبيان البداية، مراجعة الخطة، والضغط على «ابدأ رحلتي».
  - تم التحقق من ثبات تاريخ البداية وحساب اليوم 1 بدقة دون تأثر بإعادة تحميل الصفحة.
- **اختبار محاكاة الأيام المفصلية**:
  - محاكاة اليوم 1 (المرحلة الأولى - التأسيس).
  - محاكاة اليوم 30 و31 (الانتقال السلس من مرحلة التأسيس إلى مرحلة الانضباط).
  - محاكاة اليوم 210 و214 (ظهور ختام الرحلة وفتح رسالة اليوم الأول الموثقة).
- **اختبار المهام ونقاط الخبرة**:
  - إضافة مهمة، إكمالها، والتحقق من إضافة الـ XP لمرة واحدة فقط دون تكرار عند النقر المتعدد أو التحديث.
  - اختبار تأجيل المهمة 3 مرات، والتحقق من ظهور اقتراح التكيف الذكي بالقواعد المحلية.
- **اختبار الأرشيف والصور المحلية**:
  - إضافة صورة مرحلية، التأكد من ضغطها وحفظها في IndexedDB كـ Base64، وبقائها بعد إعادة فتح التطبيق.
- **اختبار النسخ الاحتياطي**:
  - تصدير نسخة JSON كاملة، تعديل البيانات، ثم استيراد النسخة والتأكد من استعادة كافة السجلات بنجاح بعد الفحص.
- **اختبار العمل دون إنترنت**:
  - فصل الاتصال وملاحظة ظهور مؤشر وضع عدم الاتصال وعمل كافة صفحات ونماذج التطبيق بسلاسة تامة.
